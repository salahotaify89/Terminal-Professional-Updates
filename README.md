# Terminal Professional — Public Update Channel

Token-free distribution channel. Contains only `update.json` and release APKs.

- Clients read `update.json` over plain HTTPS (no GitHub token).
- Source code stays in the private repository.
- Verify APK with the published SHA-256 and the app’s signing certificate.

## Stable URLs

- `https://raw.githubusercontent.com/salahotaify89/Terminal-Professional-Updates/main/update.json`
- `https://cdn.jsdelivr.net/gh/salahotaify89/Terminal-Professional-Updates@main/update.json`
- Latest APK: GitHub Releases on this repository
